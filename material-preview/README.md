# 材质设计预览程序

零第三方依赖的材质设计预览系统：内置一套真实的 GLSL ES 3.00 子集编译管线
（预处理 → 词法 → 语法 → 语义 → JS 代码生成 → 动态模块链接），配合 CPU 软件
光栅化渲染，实现可切换法线贴图、透明模式与光照选项的材质预览。所有着色结果与
编译状态均由实际运算产生，不存在"只写选项状态、渲染永远走默认着色器"的捷径。

运行环境：Node.js >= 18（开发验证版本 v22.23.4），无需安装任何依赖、无需 GPU。

## 一、图形入口（主入口）

```bash
node src/cli.js serve
# 或 npm start
```

启动后在浏览器打开（以终端实际打印的端口为准，默认 8123）：

```
http://localhost:8123/
```

图形界面即着色器预览的主入口，全部预览、编译、诊断工作都在此完成：

- **场景流送视窗**：视口画面由服务端真实渲染后以 PNG 帧流送，帧头携带
  `x-variant-key`、`x-fallback`、`x-render-ms` 等实际编译/渲染状态；可切换
  球体 / 立方体 / 圆环三个自制模型并开启自动旋转。
- **结构选项（影响编译结构）**：法线贴图开关、透明模式（不透明 / Alpha 测试 /
  Alpha 混合）、光照模式（无光照 / Lambert / Blinn-Phong PBR）。每次切换都会
  触发真实的预处理与编译，界面明确显示"当前采用变体"与"等待编译变体"。
- **数值参数（仅更新 Uniform，不重编译）**：基础色、粗糙度、金属度、自发光、
  灯光强度、Alpha 截断值、法线强度。拖动滑块只更新 uniform，变体缓存数量不变。
- **编译卡片与变体缓存列表**：显示每次编译的耗时、缓存命中、变体身份 key 与
  目标状态（混合/深度写入）。
- **故障注入区**：可提交非法 GLSL，界面弹出编译诊断（阶段、行列号、消息），
  视口切换为醒目的品红棋盘格**替代材质**，旧管线不会伪装新效果已生效。
- **事件日志**：通过 SSE 实时展示编译、帧渲染、预热、故障等事件。

## 二、命令行（仅作辅助）

```bash
# 渲染一帧到 PNG（辅助验证，主预览仍走图形界面）
node src/cli.js render --out frame.png [--material 材质ID]

# 固定操作序列基准：测量首次切换卡顿、新增变体数、缓存命中与复用
node src/cli.js bench

# 按已知场景需求、有限预算预热（可被取消，不枚举全部组合）
node src/cli.js prewarm --max-variants 4 --budget-ms 2000

# 故障注入：验证失败诊断与替代材质路径
node src/cli.js fault
```

## 四、关键设计

### 结构选项与数值参数分离

- 结构选项（`NORMAL_MAP` / `BLEND_MODE` / `LIGHTING`）作为预处理宏参与
  `#if` 分支，改变实际参与编译的源代码，产生不同管线变体。
- 数值参数全部是 uniform，改动只写 uniform 缓冲，不触发任何编译。

### 缓存身份

变体 key 由编译器版本、管线类型、**预处理后顶点/片元源码哈希、顶点布局哈希、
目标状态哈希**共同构成：

```
v1|graphics|s<源哈希>|l<布局哈希>|t<目标状态哈希>|vs<顶点哈希>|fs<片元哈希>
```

结构不同的材质不可能命中同一缓存条目；非法结构值直接被拒绝（`INVALID_STRUCT`），
不会静默落到默认缓存。

### 编译失败与替代材质

预处理/解析/语义各阶段的错误都保留带行列号的 `CompileDiagnostic`，失败结果单独
缓存（不反复重试），同时挂载固定的品红棋盘格 fallback 变体并在渲染帧与界面上
显式标记 `isFallback`。

### 有限可取消的预热

预热只接收"已知场景需要"的结构清单，受 `maxVariants` 与 `timeBudgetMs` 双重
预算约束，并支持 `cancelToken` 取消；不会在启动时枚举全部组合。

## 五、目录结构

```
src/shader/   GLSL 子集编译器：预处理、词法、语法、语义/代码生成、内置函数、值类型、材质模板
src/core/     变体身份 key、管线管理器（缓存/诊断/fallback/预热）、预览场景服务
src/render/   程序化网格与纹理、CPU 软件光栅化、PNG 编码
src/server/   HTTP 服务：静态界面、控制 API、PNG 帧流送、SSE 事件
public/       图形界面（原生 HTML/CSS/JS）
tests/        零依赖串行测试运行器与用例
```
